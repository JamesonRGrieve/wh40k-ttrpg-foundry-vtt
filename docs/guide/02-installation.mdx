# Installation and updating

## Requirements

- **Foundry VTT version 14.** The manifest declares 14 as both minimum and maximum; verified on 14.368. Other major versions are not supported.
- **No content is required to start.** Book content is not included; you supply it.

## Install

1. On Foundry's setup screen, open **Game Systems**.
2. Click **Install System**.
3. Paste a manifest URL into **Manifest URL** and click **Install**.

### Release channels

Use one channel per Foundry installation.

**Official release**: versioned releases. Use this for regular games. The URL always resolves to the newest release.

```
https://github.com/JamesonRGrieve/wh40k-ttrpg-foundry-vtt/releases/latest/download/system.json
```

**Nightly**: a rolling pre-release build of the latest development code, rebuilt on every change. Expect rough edges.

```
https://github.com/JamesonRGrieve/wh40k-ttrpg-foundry-vtt/releases/download/nightly/system.json
```

Both channels ship the system code, its licence and only the public, generic compendium packs. **Neither channel includes copyrighted book content.**

## Update

Both manifest URLs are stable, so Foundry's update check works.

1. Back up your world.
2. Open **Game Systems** on the setup screen.
3. Click **Update** on WH40K RPG (Unofficial), or **Update All**.

## Adding game content

The system reads origin paths, talents, skills, weapons, conditions, critical effects and other content from compendium packs. Without them:

- The Origin Path Builder shows **No origins available for this step**, unless the GM has created origin path items in the world.
- The token condition list contains only Foundry's **Dead** marker.
- Critical damage cards show **Critical Effect text unavailable (content pack not installed).**

You can still create actors, roll characteristics and skills, and build items by hand in your world.

## First steps

1. Create a world using **WH40K RPG (Unofficial)**.
2. As GM, open **Game Settings → Configure Settings → WH40K RPG** and set **Primary Game System** to the line you are running.
3. Review the other world settings, especially the house rules, before your first session. See [Game Settings](?path=/docs/guide-game-settings--docs).
