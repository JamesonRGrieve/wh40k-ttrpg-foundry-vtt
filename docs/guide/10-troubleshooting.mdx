# Troubleshooting and getting help

## Common messages

### Missing content

- **No origins available for this step**: no origin path content is installed for this line. Install your content packs, or have the GM create origin path items in the world.
- **Critical Effect text unavailable (content pack not installed).**: install the content packs for your line.
- **The token status list only shows Dead**: conditions come from your content packs for the **Primary Game System**. Install the packs and check that setting.
- **"… item(s) could not load their compendium data and are incomplete"**: items on an actor point at missing compendium entries. Install and enable the packs they came from.

See [Installation and Updating](?path=/docs/guide-installation-and-updating--docs).

### Attacks and movement

- **"Attacks can only be made during an active combat encounter."**: start an encounter that includes the attacker's token, or have the GM disable **Require Active Combat to Attack**.
- **"This weapon must be equipped before it can be used to attack."**: use **Draw Weapon** on the Combat tab.
- **"This weapon is jammed and cannot fire."**: use **Clear Jam**, then reload.
- **"This weapon is out of ammunition."**: use **Reload**.
- **"Auto-roll damage failed …"**: use **Roll Damage** on the attack card.
- **"It is not this combatant's turn — only the active combatant may move."**: wait for your turn, or ask the GM to change **Movement Automation**.
- **"That move exceeds the movement remaining this turn"**: pick Charge or Run, or wait for your next turn.

### Characters and items

- **"This skill has test variants — enable …"**: the GM can enable **Homebrew: Awareness Sense Channels**.
- **Dropping a talent opens the Advancement window**: talents are bought with XP. Buy it there.
- **Dropping an origin path is refused**: use the builder (d20 icon), or have the GM enable **Freeform Character Editing**.
- **No Career Selected** in the Advancement window: complete the Origin Path Builder first.
- **An item sheet has no edit controls**: the item is in a compendium or locked by **Freeform Character Editing**. Edit the compendium source, or have the GM enable the setting.

## Before reporting a problem

1. Confirm you are on Foundry VTT version 14.
2. Update to the latest system version for your channel.
3. Disable other modules to rule out a conflict.
4. Open the browser console (F12) and note any red errors. For detailed system logs, run this and repeat the problem:

```js
game.wh40k.debug = true;
```

## Getting help

Report bugs and request features on the GitHub issue tracker:

**[github.com/JamesonRGrieve/wh40k-ttrpg-foundry-vtt/issues](https://github.com/JamesonRGrieve/wh40k-ttrpg-foundry-vtt/issues)**

Search existing issues first, including closed ones, and add to a match if you find one. A new issue should include:

- Foundry and system versions;
- the game line;
- steps to reproduce;
- console errors;
- a screenshot of the sheet, dialog or chat card, if relevant.

Do not post rulebook text in issues. The project cannot include copyrighted book content.
