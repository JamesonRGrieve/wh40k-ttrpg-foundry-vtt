# WH40K RPG for Foundry VTT

WH40K RPG is an unofficial, fan-made game system for [Foundry Virtual Tabletop](https://foundryvtt.com/). It runs the Warhammer 40,000 d100 roleplaying games on one codebase, with per-line sheets and rules where the games differ. It requires **Foundry VTT version 14**.

In Foundry's system list it appears as **WH40K RPG (Unofficial)**.

## Supported game lines

Dark Heresy 2nd Edition, Dark Heresy 1st Edition, Rogue Trader, Black Crusade, Only War and Deathwatch. Each line has character, NPC and vehicle actors, an Origin Path Builder and its own sheet panels. Rogue Trader adds voidcraft.

## No book content is included

The system is a rules engine and a set of sheets. It ships **no rulebook text, no stat blocks and no item, talent or origin descriptions**. Talents, weapons, origin paths, conditions and other game content come from compendium packs you supply. Without them the system still works, but lists such as origin choices and conditions are empty. See [Installation and Updating](?path=/docs/guide-installation-and-updating--docs).
