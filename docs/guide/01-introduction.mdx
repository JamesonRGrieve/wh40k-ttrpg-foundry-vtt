# WH40K RPG for Foundry VTT

WH40K RPG is an unofficial, fan-made game system for [Foundry Virtual Tabletop](https://foundryvtt.com/). It runs the Warhammer 40,000 d100 roleplaying games on one shared codebase, with per-line sheets and rules where the games differ.

In Foundry's system list it appears as **WH40K RPG (Unofficial)**.

## Supported game lines

| Game line | What you get |
| --- | --- |
| Dark Heresy 2nd Edition | Character, NPC and vehicle actors; Origin Path Builder (Home World, Background, Role, optional Elite Advance, characteristics, Equip Acolyte); warband Subtlety; Influence, Requisition and Throne Gelt |
| Dark Heresy 1st Edition | Character, NPC and vehicle actors; Origin Path Builder (Home World, Career, characteristics) |
| Rogue Trader | Character, NPC, vehicle and voidcraft actors; Origin Path Builder (Home World through Career, optional Lineage) |
| Black Crusade | Character, NPC and vehicle actors; Origin Path Builder (Race, Archetype, Pride, Disgrace, Motivation); Chaos Alignment, Gifts of the Gods, rituals and apotheosis panels |
| Only War | Character, NPC and vehicle actors; Origin Path Builder (Regiment, Speciality); Comrade, Regiment, Orders and Squad Logistics panels |
| Deathwatch | Character, NPC and vehicle actors; Origin Path Builder (Chapter, Speciality); Cohesion, Combat Mode, Renown, Requisition and Mission Oath panels |

The system targets **Foundry VTT version 14** only.

## No book content is included

The system is a rules engine and set of sheets. It ships **no rulebook text, no stat blocks and no item, talent or origin descriptions**. Talents, weapons, origin paths, conditions and other game content come from compendium packs that you supply yourself. Without them the system still works as a framework, but lists such as origin choices and conditions will be empty. See [Installation and Updating](?path=/docs/guide-installation-and-updating--docs).
